# Plain Timeline

[English](README.md)

ノートにプレーンテキストで年表を書くと、縦か横、等間隔のカードか時間に比例した時間軸で表示するObsidianプラグインです。年だけ・年月・年月日、紀元前、今も続いている期間にも対応しています。

![縦のカード](docs/images/vertical-cards.jpg)

## 4通りの表示

年表ごとに向きと見た目を選べます。年表右上の小さな切り替えボタンを押すか、ブロックの中に書きます。

| | カード(等間隔、出来事向き) | 時間軸(長さが時間に比例、期間向き) |
| --- | --- | --- |
| **縦** | ![](docs/images/vertical-cards.jpg) | ![](docs/images/vertical-scale.jpg) |
| **横** | ![](docs/images/horizontal-cards.jpg) | ![](docs/images/horizontal-scale.jpg) |

## 書き方

````markdown
```plain-timeline
> タイトル フランス革命
- [1789-07-14] バスティーユ襲撃 | パリで革命が始まる
@ [1792-09-21~1804-05-18] 第一共和政 | 王政の廃止
@ [1793-09~1794-07] #red 恐怖政治 | [[ロベスピエール]]と公安委員会
- [-490] マラトンの戦い
= [1815-06-18] ワーテルローの戦い
```
````

### 行

| 行 | 意味 |
| --- | --- |
| `- [日付] 名前 \| 説明` | 出来事。`[1914~1918]` のような範囲も書けます。 |
| `@ [開始~終了] 名前 \| 説明` | 期間。終わりを空けた `[2020~]` は「現在まで」になります。 |
| `= [日付] 名前` | 目印(日付は1つだけ)。 |
| 日付の直後の `#red` | その項目の色。blue, green, purple, orange, cyan, pink, yellow, red, gray。それ以外の `#単語` は名前の一部のままです。 |
| `# 文` | コメント(表示されません)。 |
| `- [2026-09-01, 2026-09-10] 名前` | 1行に複数の日付を書くと、同じ名前と説明の項目がそれぞれできます(`,` `、` でも区切れます)。 |
| 項目の下の字下げした行 | 説明の続きになります。中では、空行で区切った複数の段落、箇条書き、リンクなど、Markdownがそのまま使えます。 |

長い項目は、たとえば次のように書けます。

````markdown
```plain-timeline
- [2026-09-01, 2026-09-10~2026-09-12] 中間試験 | 範囲は1〜3章
  教科書と配布資料を持っていく。

  - 問題集A
  - 問題集B
```
````

### 指定

| 指定 | 意味 |
| --- | --- |
| `> 向き 横` | この年表を横にします(既定は縦)。 |
| `> 見た目 時間軸` | 時間に比例させて描きます(既定はカード)。 |
| `> タイトル 文` | 年表の上にタイトルを出します。 |
| `> 開始 1700` / `> 終了 1900` | 時間軸の範囲を固定します。範囲外の項目は端に寄せて表示し、お知らせに出します。 |
| `> 今日` | 今日の目印を足します。 |
| `> 間隔 詰める` | この年表だけ間隔を詰めます。 |
| `> 説明 ホバー` | この年表だけ、説明をマウスを載せたときに出します(`表示` で常に表示)。 |
| `> 高さ 300` | 高さを固定し、中をスクロールさせます。 |

英語でも書けます(`> orientation horizontal`、`> look scale`、`> title …`、`> start`、`> end`、`> today`、`> density compact`、`> desc hover`、`> height`)。切り替えボタンで書き換えるときは、そのブロックで使っている言語に合わせます。

### 日付

日付は年(`1789`)、年月(`1789-07`)、年月日(`1789-07-14`)のどれでも書けます。負の年は紀元前です(`-490` → 前490年)。`-13800000000` のような非常に大きな年も描けます。月日と一緒に書いた2桁の年は「2桁の年」の設定に従う(`19-03-04` → 2019年)ので、紀元1〜99年は4桁で書いてください(`0079-08-24`)。

設定で、日付の並びを日-月-年や月-日-年に変えられます。区切りは「-」「/」「.」なしのどれでもよく(`20261021`、`202610`、`21/10/2026`、`211026` など)、日本語入力の全角数字や「～」もそのまま使えます。

読めない日付、知らない指定やその値、`> 開始`・`> 終了` の範囲外の項目は、黙って消さずに年表の下へ小さくお知らせとして出します。

## 説明とリンク

`|` の後ろが説明です。名前と説明の中では `[[リンク]]` も `[表示](URL)` も使えます。横の時間軸では、項目にマウスを載せると説明が横に出ます。「常に表示」の設定なら、軸の下に一覧も出ます。

項目をクリックすると、項目の中のリンク、同じ名前のノート、このノートの中でその名前が最初に出てくる場所、の順に開きます。項目の中にリンクがある場合は、そのリンクだけが押せます(設定で変えられます)。⌘/Ctrlクリックで新しいタブに開きます。Tabキーで項目をたどってEnterで開け、リンク先はObsidianのページプレビューで見られます。

## 時間軸

時間軸の目盛りは、日・週・月・年の暦の単位から表示幅に合うものを選び、両端に半目盛り分の余白をとって、年が変わる所には年を添えます。項目が詰まっている所では軸を少し伸ばすので、ラベルは重なりません。

## ノート表示

見出しで書いた記録も、時系列として読めます。**設定 → ノート表示** にフォルダを書くと(例 `Projects/*/Worklog`。`*` はフォルダ名1つ、`**` は任意の深さ)、その中のノートでは閲覧モードのとき、時刻で始まる `##` 見出し(`## 2026-10-21 23:52 開始`、`## 09:30 朝会`、`## 確認(2026-10-22T00:23+09:00)` のように括弧の中の時刻も可)を、左の列に時刻、その横にタイトル、下の本文を線でつないだ1枚のカードとして表示します。日付は変わる所だけに出ます。時刻のない見出しはそのままです。ノートの中身は変えないので、編集はいつもどおりできます。

日付だけの見出し(`### 2026-10-21 公開`、または `公開(2026-10-21)`)はその日の項目になり、時刻の列に日付を出します。時刻だけの見出し(`## 09:30 朝会`)は、上にある日付つきの見出しの日付を使い、なければノートのプロパティ `date` かファイル名の `YYYY-MM-DD` を使います。デイリーノートがそのまま日付つきの時系列になります。日付は `2026/10/21` とも書けます。時刻は書かれたまま表示し、`+09:00` や `JST` などの時差は換算しません。時刻をクリック(またはEnter)すると、その項目の位置でノートを編集できます。

ノートごとに、プロパティへ `plain-timeline: notes` または `plain-timeline: off` と書くと、対象に入れたり外したりできます。フォルダの後ろに色を書くと(`Projects/*/Worklog #green`)、その中のノートがその色になります(書かなければ期間の色の先頭)。見出しのレベルは設定で変えられ、ノートごとにはプロパティ `plain-timeline-heading: 3` で変えられます。

## スマホ・タブレット

スマホでは縦の表示が1列になります。スマホとタブレットではボタンや項目を大きくし、横の時間軸の項目をタップすると年表の下に詳細が出ます。幅の広い年表は、続きがある側の端をフェードさせます。

## 設定

言語(English / 日本語 / Obsidianに合わせる)・既定の向きと見た目・ブロック内の日付の並び・2桁の年・日付の表示(言語に合わせる、ISO、`DD/MM/YYYY` や `YYYY年M月D日` のような自分で指定する書式)・紀元前の表記・説明を常に出すかホバーで出すか・項目のリンク化・切り替えボタン・期間の色とその順番・間隔・並び順・横の時間軸の最小幅・読めない行のお知らせ。
