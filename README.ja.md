# Plain Timeline

[English](README.md)

ノートにプレーンテキストで年表を書くと、縦か横、等間隔のカードか時間に比例した時間軸で表示するObsidianプラグインです。年・年月・年月日、紀元前、今も続いている期間、宇宙の歴史のような長い時間も扱えます。時刻つきの見出しで書いた記録を、時系列として表示することもできます。

画像はすべてPC・英語表示のものです。

![縦のカード](docs/images/vertical-cards.png)

## はじめに

`plain-timeline` のコードブロックに、次のように書きます。

````markdown
```plain-timeline
> タイトル フランス革命
- [1789-07-14] バスティーユ襲撃 | パリで革命が始まる
@ [1792-09-21~1804-05-18] 第一共和政 | 王政の廃止
@ [1793-09~1794-07] 恐怖政治 | [[ロベスピエール]]と公安委員会
- [1804-12-02] ナポレオンが皇帝に即位
= [1815-06-18] ワーテルローの戦い
```
````

`-` は出来事、`@` は期間、`=` は目印です。`|` の後ろが説明です。`>` で始まる行は、その年表の指定(オプション)です。

## 4通りの表示

年表ごとに、向き(縦・横)と見た目(カード・時間軸)を選べます。年表右上のボタンで切り替えると、その選択がブロックに書き込まれます。`> 向き` と `> 見た目` で自分で書くこともできます。

| | カード(等間隔、出来事向き) | 時間軸(長さが時間に比例、期間向き) |
| --- | --- | --- |
| **縦** | ![](docs/images/vertical-cards.png) | ![](docs/images/vertical-scale.png) |
| **横** | ![](docs/images/horizontal-cards.png) | ![](docs/images/horizontal-scale.png) |

横の時間軸では、期間の帯には名前だけを書きます。帯より長い名前は帯の中で折り返して帯を縦に伸ばし、とても短い帯では名前を帯に沿って縦書きにします。文字のせいで期間が長く見えることはありません。続いている期間は同じ段に並び、同時に始まる期間は長いものから順に上の段に並びます。日付と説明は、マウスを載せたときの吹き出しと、軸の下の一覧に出ます。

## 項目の書き方

| 行 | 意味 |
| --- | --- |
| `- [日付] 名前 \| 説明` | 出来事。`[1914~1918]` のような範囲も書けます。 |
| `@ [開始~終了] 名前 \| 説明` | 期間。終わりを空けた `[2020~]` は「現在まで」になります。 |
| `= [日付] 名前` | 目印(日付は1つだけ)。 |
| 日付の直後の `#red` | その項目の色。blue, green, purple, orange, cyan, pink, yellow, red, gray。それ以外の `#単語` は名前の一部のままです。 |
| `- [2026-09-01, 2026-09-10] 名前` | 1行に複数の日付を書くと、同じ名前と説明の項目がそれぞれできます(`,` `、` でも区切れます)。 |
| 項目の下の字下げした行 | 説明の続きになります。空行で区切った段落、箇条書き、リンクなど、Markdownがそのまま使えます。 |
| `# 文` | コメント(表示されません)。 |

````markdown
```plain-timeline
- [2026-09-01, 2026-09-10~2026-09-12] 中間試験 | 範囲は1〜3章
  教科書と配布資料を持っていく。

  - 問題集A
  - 問題集B
```
````

### 日付

日付は年(`1789`)、年月(`1789-07`)、年月日(`1789-07-14`)のどれでも書けます。負の年は紀元前です(`-490` → 前490年)。`-13800000000` のような何十億年の幅も描けます。紀元1〜99年は4桁で書いてください(`0079-08-24`)。月日と一緒に書いた2桁の年は「2桁の年」の設定に従います(`19-03-04` → 2019年)。

設定で、日付の並びを日-月-年や月-日-年に変えられます。区切りは「-」「/」「.」なしのどれでもよく(`20261021`、`21/10/2026` など)、全角数字や「～」もそのまま使えます。

読めない日付や知らない指定は、黙って消さずに年表の下へ小さくお知らせとして出します。

![紀元前、ライトテーマ](docs/images/bce-light.png)

## 指定(オプション)

指定は `>` で始まる行に、名前と値を書きます(`> 向き 横`)。1行に1つずつ、ブロックの中のどこに書いてもかまいません(先頭にまとめると読みやすくなります)。指定はその年表だけに効き、書かなかったものはプラグインの設定に従います。どの指定にも英語の名前があり、`> orientation horizontal` と書いても同じです。

### 表示

| 書き方 | すること |
| --- | --- |
| `> 向き 横` | 横に並べます(既定は `縦`)。 |
| `> 見た目 時間軸` | 時間に比例させて描きます(`カード` は等間隔)。 |
| `> タイトル フランス革命` | 年表の上にタイトルを出します。 |
| `> 高さ 300` | 高さを300pxに固定し、中をスクロールさせます。 |
| `> 間隔 詰める` | 項目同士の間隔を詰めます(既定は `ゆったり`)。 |
| `> 説明 ホバー` | 説明をマウスを載せたときだけ出します(`表示` で常に表示)。 |

### 範囲

| 書き方 | すること |
| --- | --- |
| `> 開始 1700` / `> 終了 1900` | 軸の始まりや終わりを固定します。範囲外の項目は端に寄せて表示し、年表の下のお知らせに出します。 |
| `> 今日` | 今日の目印を足します。 |

### 縮尺(時間軸の並べ方)

時間軸の見た目で、時間を軸にどう並べるかを `> 縮尺` で決めます。ふつうは書かなくてかまいません。既定の **自動** は、日付がほどよく散らばっていれば比例のままにし、比例では大半の項目が一点に潰れてしまうときだけ切り替えます。比例でない縮尺のときは、年表の下にそう書きます。切り替えボタンの横の選択欄からも変えられ、**設定 → 時間軸の縮尺** で全部の年表の既定を決められます。

| 書き方 | 軸 | 向いている年表 |
| --- | --- | --- |
| `> 縮尺 自動` | 日付から選びます(比例・最近を広く・均等)。 | たいていの年表。 |
| `> 縮尺 比例` | 長さが時間にそのまま比例します。 | 歴史、プロジェクト、旅行。 |
| `> 縮尺 最近を広く` | 最後の項目から見た「何年前」の対数。最近ほど広くなります。 | 宇宙の年齢と最近の1万年を1本に。 |
| `> 縮尺 始まりを広く` | 最初の項目からの「何年後」の対数。初めほど広くなります。自動では選ばれません。 | ビッグバン直後の数分など。 |
| `> 縮尺 均等` | 日付と日付の間を同じくらいの幅にそろえます。長さは時間に比例しません。 | ほかの縮尺では読めないもの。 |

| `> 縮尺 最近を広く`(自動で選ばれた例) | `> 縮尺 均等` |
| --- | --- |
| ![](docs/images/axis-recent.png) | ![](docs/images/axis-even.png) |

````markdown
```plain-timeline
> タイトル ビッグバンから月面着陸まで
- [-13800000000] ビッグバン
- [-13799620000] 宇宙の晴れ上がり | ビッグバンの約38万年後
@ [-4600000000~-4500000000] 太陽系の誕生
- [-66000000] 恐竜の絶滅
- [-300000] ホモ・サピエンス
- [1969-07-20] 月面着陸
```
````

比例の軸のまま一部だけ細かく見たいときは、その区間だけ広げます。区間ごとに1行書きます。

| 書き方 | すること |
| --- | --- |
| `> 広げる 1939~1945 5倍` | 1939〜1945年をほかの5倍の幅で描きます。 |

### 地質時代などの単位

| 書き方 | すること |
| --- | --- |
| `> 単位 百万年前` | 日付を「何百万年前」で書き、そのまま表示します。`@ [538.8~251.9] 古生代` は「538.8 Ma – 251.9 Ma」と表示されます。`十億年前`・`千年前`、`Ma`・`Ga`・`ka` も使えます。 |

![地質時代](docs/images/geologic.png)

````markdown
```plain-timeline
> タイトル 地質時代
> 単位 百万年前
@ [2500~538.8] 原生代
@ [538.8~0] 顕生代
@ [538.8~251.9] 古生代
@ [251.9~66] 中生代
@ [66~0] 新生代
@ [2.58~0] 第四紀
```
````

## 説明とリンク

`|` の後ろが説明で、項目の下の字下げした行も説明に加わります。名前と説明の中では `[[リンク]]` も `[表示](URL)` も使えます。項目をクリックすると、項目の中のリンク、同じ名前のノート、このノートの中でその名前が最初に出てくる場所、の順に開きます。項目の中にリンクがある場合は、そのリンクだけが押せます(設定で変えられます)。⌘/Ctrlクリックで新しいタブに開き、TabキーとEnterでも操作でき、リンク先はObsidianのページプレビューで見られます。

## ノート表示

見出しで書いた記録を、時系列として読めます。**設定 → ノート表示** にフォルダを1行に1つ書きます(例 `Projects/*/Worklog`。`*` はフォルダ名1つ、`**` は任意の深さ)。その中のノートでは閲覧モードのとき、日付や時刻で始まる見出しが項目になり、左の列に時刻、その横にタイトル、下の本文を線でつないだカードとして表示します。ノートの中身は普通のMarkdownのままです。

![ノート表示](docs/images/note-view.png)

```markdown
## 2026-10-21 23:52 評価の計画
最初の実行の前に、採点基準を固定した。

## 2026-10-22 00:02 採点の校正
過去のレポート2本を採点し直した。

## 00:23 基準版を測定
時刻だけの見出しは、上の見出しの日付を引き継ぐ。
```

- 見出しの先頭には、日付と時刻(`2026-10-21 23:52`、`2026/10/21 9:30`、`2026-10-22T00:23+09:00`)、日付だけ(`2026-10-21`)、時刻だけ(`09:30`)のどれでも書けます。末尾の括弧の中でもかまいません(`## 確認(2026-10-22 00:23)`)。
- 時刻だけの見出しは、上の見出しの日付を引き継ぎます。なければノートのプロパティ `date` かファイル名の `YYYY-MM-DD` を使うので、デイリーノートがそのまま日付つきの時系列になります。
- 時刻は書かれたまま表示し、時差は換算しません。日付も時刻もない見出しは、普通の見出しのままです。
- 時刻をクリック(またはEnter)すると、その項目の位置でノートを編集できます。

フォルダごと・ノートごとの指定:

| 場所 | 書き方 | すること |
| --- | --- | --- |
| 設定 → ノート表示 | `Projects/*/Worklog #green` | フォルダの後ろに色を書くと、その中のノートがその色になります(書かなければ期間の色の先頭)。 |
| ノートのプロパティ | `plain-timeline: notes` / `plain-timeline: off` | フォルダに関係なく、このノートを時系列で表示する/しない。 |
| ノートのプロパティ | `plain-timeline-heading: 3` | このノートでは `###` の見出しを項目にします(既定のレベルは設定で決めます)。 |

## 設定

設定は全部の年表の既定です。ブロックに書いた指定は、その年表だけで設定より優先されます。

言語(English / 日本語 / Obsidianに合わせる)・既定の向きと見た目・時間軸の縮尺(自動・比例・最近を広く・始まりを広く・均等)・ブロック内の日付の並び・2桁の年・日付の表示(言語に合わせる、ISO、`YYYY年M月D日` のような自分で指定する書式)・紀元前の表記・説明を常に出すかホバーで出すか・項目のリンク化・切り替えボタン・期間の色とその順番・間隔・並び順・横の時間軸の最小幅・読めない行のお知らせ・ノート表示のフォルダと見出しのレベル。

![ライトテーマ](docs/images/light.png)

## スマホ・タブレット

スマホでは縦の表示が1列になります。スマホとタブレットではボタンや項目を大きくし、横の時間軸の項目をタップすると年表の下に詳細が出ます。幅の広い年表は、続きがある側の端をフェードさせます。
