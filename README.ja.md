# Plain Timeline(日本語)

ノートにプレーンテキストで年表を書くと、縦か横、等間隔のカードか時間に比例した時間軸で表示するObsidianプラグイン。年だけ・年月・紀元前にも対応する。使い方の詳細は英語の [README](README.md) を参照。

## 書き方

````markdown
```plain-timeline
- [1789-07-14] バスティーユ襲撃 | パリで革命が始まる
@ [1792-09-21~1804-05-18] 第一共和政 | 王政の廃止
= [1815-06-18] ワーテルローの戦い
> 向き 横
> 見た目 時間軸
```
````

`-` は出来事、`@` は期間、`=` は目印。期間は `~` で、紀元前は負の年(`-490`)で書く。終わりを空けた `[2020~]` は「現在まで」になる。`> タイトル`、`> 開始` `> 終了`(時間軸の範囲)、`> 今日`(今日の目印)、`> 間隔 詰める`、`> 説明 ホバー` も書ける。読めない行は年表の下に警告として出る。向きと見た目は、年表右上のボタンでも切り替えられる(`> orientation horizontal` `> look scale` の英語表記も可)。設定で表示言語を日本語にすると、日付は「1789年7月14日」、紀元前は「前490年」の形になる。

行の書き方は [Chronos Timeline](https://github.com/clairefro/obsidian-plugin-chronos)(MIT)と互換。コードは使っていない。
